Presented at [MCHPC 2022](https://passlab.github.io/mchpc/mchpc2022/) at SC22 in Dallas, Texas. High-performance stencil codes are typically tuned by transforming loop structure, but this work takes a different approach: the [Bricks library](https://github.com/CtopCsUtahEdu/bricklib) improves performance by transforming data layouts to match the memory hierarchy instead, enabling significant speedups for structured-grid computations without manual code restructuring. This was joint work with Dr. Tuowen Zhao, [Dr. Hans Johansen](https://crd.lbl.gov/divisions/amcr/computational-science-dept/anag/about/staff-and-postdocs/hans-johansen/), and [Dr. Samuel Williams](https://crd.lbl.gov/divisions/amcr/computer-science-amcr/par/members/staff/samuel-williams/) at [Lawrence Berkeley National Laboratory](https://crd.lbl.gov); slides [here](https://github.com/benSepanski/myTalks/tree/91e56341d5d8e44e0f3fd8f8b20bf3eb049170f7/2022-11-13-Maximizing-Performance-Through-Memory-Hierarchy-Driven-Data-Layout-Transformations).
